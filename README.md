# 流浪者之憩 · AI Tavern

**一款中文单人跑团游戏，把视觉小说式演出、D20 检定和回合制小队战斗放在同一场冒险里。**

![流浪者之憩的酒馆大厅场景美术](public/scenes/tavern-hall.webp)

推开酒馆的门，艾琳会递来一份委托。你可以去古墓找失落的宝物，替镇民查一桩失踪案，也可以从夺心魔的飞船上一路逃到博德之门。途中你可以选剧本给出的行动，也可以自己打字说想做什么。遇到危险时，故事切换到战斗面板，由你指挥队伍里的每一个人。

> **当前状态 · 可本地游玩**  
> 已经可以从领委托、投骰、探索和打遭遇战，一直玩到战后结算与剧本结局。内置六个剧本，可操控 1–4 名角色，战术成长覆盖 1–5 级。开启「本地演练」即可用固定剧本和本地场景续写体验这套流程。配置模型后，还可以让 AI 根据行动和战役记录即兴主持。

## 本地启动

准备 Node.js 20.9 或更新版本，本次测试使用 Node.js 24。获取项目并启动：

```bash
git clone https://github.com/Annoyinghh/ai-tavern.git
cd ai-tavern
npm ci
npm run dev
```

打开 [酒馆大厅](http://localhost:8080)。首次游玩可以在酒馆操作栏勾选「本地演练」，然后点「跟艾琳练一遍」或「去看委托」。

| 入口 | 可以做什么 |
| --- | --- |
| [酒馆大厅](http://localhost:8080/) | 听迎宾、练习操作、招募同伴、看委托信、继续上次的战役 |
| [跑团舞台](http://localhost:8080/game) | 阅读逐句演出、选择或输入行动、投骰、打战斗、读写存档 |
| [角色档案](http://localhost:8080/character) | 编辑主角的种族、职业、属性与形象，预览待机、交谈和出手立绘 |
| [剧本工坊](http://localhost:8080/scripts) | 创建章节和分支、编辑世界资料、查看分支图、交换剧本 JSON |

## 第一次怎么玩

### 先熟悉操作

点击「跟艾琳练一遍」，按顺序练习接委托、读对话、做检定、在战斗中靠近目标，以及导出存档。每节都有操作示例和普通话语音。想直接体验剧情，可以接《酒馆风波》，在几次选择内走到结局。

### 打完第一场遭遇战

1. 在大厅打开「整备队伍」，用现有主角出发，或者再招募同伴。队伍第一位是叙事主角，其他人也由你操作。选好队员和起始等级后，点「去看委托」。战役开始后编队锁定，改队伍需先「返回整备」。
2. 接受《地牢探险》，在开场选择「接受任务，出发前往墓穴」。抵达「墓穴入口」后点「主动侦察」，本地演练会触发该场景的骷髅遭遇。
3. 看先攻顺序，轮到队友时先确认距离和视线，再决定要不要移动、攻击、施法或使用药水。点「结束回合」交给下一位。敌人会自动行动，借机攻击或护盾术等玩家反应会单独提示。
4. 结束战斗后点「结算并继续故事」。打赢会发放经验和战利品，损失的生命值、法术位和物品也会带回探索。继续前进到「陷阱走廊」时，读完剧情后点「进入战斗」。击败守墓骷髅后，才能继续处理陷阱、前往宝藏室。

### 开一局长篇战役

选择《博德之门：至高主脑降临》。序章从螺壳舰的养殖舱醒来，第一道关卡就可以试试砸开舱门、破解灵能机关或撬开压力阀。之后会走过剑湾、林地、幽暗地域，最后抵达博德之门。这个剧本有 **34 个章节、4 个结局**，适合分几次玩。到达终章后，可以选择后日谈、重玩或换一份委托。

## 玩法能深入到什么程度

### 探索与检定

- **选择行动。** 剧本给出选项，你也可以自由描述行动，例如「我先检查门轴上的划痕，再问守卫刚才谁从这里经过」。接入模型后，主持会结合所在场景和已经确认的线索回应。
- **看得见怎么算。** 检定展示 D20、角色属性与熟练加值，以及目标难度 DC。总值比 DC 低至少 5 点为大失败，低 1–4 点为失败，达到 DC 或高 1–4 点为成功，高至少 5 点为大成功。
- **失败有后果。** 必经检定也有失败时的剧情走向，可能带来伤势或错过额外线索。骰点在确认前就已保存，刷新后可以接着处理同一结果。

### 战斗与成长

适合的场景可以通过「主动侦察」遇敌。剧本也可以安排必须打赢才能推进的主线战斗，例如螺壳舰舵室和霓虹数据核心的交锋。主线战斗中撤退会保留队伍的消耗，整顿后可以重打。

战斗面板会显示可选目标、距离、路线和掩护。底层按方格计算移动、地形与视线。每名角色分别管理移动、动作、附赠动作和反应。可以用疾走拉近距离，用脱离近战避免借机攻击，或从地图左侧边界带全队撤离。法术有射程、法术位、豁免、范围和专注等约束。倒地队友可能需要治疗、稳定伤势或进行死亡豁免。

| 职业 | 能实际用到的打法 |
| --- | --- |
| **法师** | 用火焰箭和魔法飞弹远程输出，命中时用护盾术应对。雷鸣波可以推开敌人，5 级可以施放会波及友军的火球术。 |
| **游侠** | 用长弓和猎人印记持续输出，必要时用疗伤术救人。5 级获得额外攻击。 |
| **圣骑士** | 可以用圣疗拉起倒地队友，或用祝福术支援队伍。2 级起能在近战命中后接至圣斩，5 级获得额外攻击。 |
| **游荡者** | 满足条件时触发偷袭，2 级起可用灵巧动作调整站位，5 级起可用直觉闪避减伤。 |

胜利后，队员分摊经验，达到阈值即可提升等级与对应能力。已有伤势和消耗会带入下一段旅程，可在队伍面板安排短休或长休。创角时可启用特定种族的少量战术特性，例如木精灵走得更远，矮人每级有额外生命值。

当前规则以 **SRD 5.2.1 的战术子集**为基础，职业能力、装备和敌人使用内置模板。子职业、专长和战斗中换武器仍在当前范围之外。各职业的法术与规则适配见 [规则支持清单](docs/rules-support.md)。

### 演出、记录与续玩

- **视觉小说式演出。** 剧情按台词推进，搭配角色立绘、表情和场景配乐。角色档案的「试衣间」可分别选择人物、外装、头像框和声线。艾琳的迎宾、六份委托和五节教程自带普通话录音。即兴台词可用本机 Qwen3-TTS 点播。
- **回看冒险。** 「回想与检定记录」可回顾经过，「战役记忆」可查看已经记录的线索、里程碑和同伴关系。可从「存档」导出 Markdown 编年史分享这一局的经历。
- **下次接着玩。** 进度自动保存在当前浏览器，也可另存多个档位。导出的战役 JSON 包含队伍资源、剧本快照、进行中的战斗、待选反应和已经投出但尚未确认的骰点。换设备或浏览器时，在「存档」里导入即可接续。清理浏览器数据前，可先导出 JSON 备份。

## 本机角色配音

Windows 使用 Python 3.12。以下命令在项目内安装 NVIDIA CUDA 推理环境并下载权重，之后合成可离线运行。

```powershell
python -m venv .venv-voice
$voicePython = ".\.venv-voice\Scripts\python.exe"
& $voicePython -m pip install torch==2.11.0 torchaudio==2.11.0 --index-url https://download.pytorch.org/whl/cu128
& $voicePython -m pip install qwen-tts==0.1.1
& $voicePython scripts/local_voice.py download
```

执行 `& $voicePython scripts/local_voice.py pilot` 生成艾琳和老汤姆的日常与险情片段，试听通过后执行 `& $voicePython scripts/local_voice.py pack` 生成完整的六人声库和固定台词。运行 `& $voicePython scripts/local_voice.py serve` 启用即兴配音，游戏和语音进程应在同一台电脑上。服务关闭时仍可播放已打包音频和阅读字幕。

游戏和语音服务都启动后，可另开终端执行 `& $voicePython scripts/local_voice.py benchmark --port 8080`。短句响应达到门槛后，刷新游戏启用即兴自动播放。使用 `scripts/local_voice.py add --help` 查看如何新增可在创角时复用的声线。

## 接入 AI 主持

| 模式 | 适合体验什么 |
| --- | --- |
| **本地演练** | 适合熟悉操作或体验固定剧本。游戏使用本地场景续写，能走已写好的分支，也能做检定、打遭遇战和存档。自由行动的回应以固定模板为主。 |
| **AI 主持** | 适合想用自由输入尝试谈判、调查或临场行动的玩家。模型读取当前剧本的设定、已到达章节、已解锁资料和相关战役记忆，提出叙述、后续选项或可用事件。程序负责校验和结算数值。 |

在游戏「设置」里填入兼容 Chat Completions 接口的 **API Key、Base URL 和模型名称**并保存，然后取消勾选「本地演练」。也可以复制 [.env.example](.env.example) 为 `.env.local`，选择一组配置，保存后重启服务。

| 服务 | 必填 | 可选 |
| --- | --- | --- |
| DeepSeek | `DEEPSEEK_API_KEY` | `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` |
| OpenAI | `OPENAI_API_KEY` | `OPENAI_BASE_URL`、`OPENAI_MODEL` |

请把真实密钥留在本机设置或 `.env.local`。如遇 HTTP 401/403，检查密钥和权限。如遇 HTTP 404，检查接口地址和模型名称。修正设置后可以重试主持，已保存的骰点会沿用。也可以手动开启「本地演练」，再点「重试主持，不重新投骰」。

## 自己写一份委托

打开「剧本工坊」，从空白剧本或内置模板开始。先写委托简介与开场，再为各章节添加选项、目标章节和检定条件。「主线战斗」可以配置敌人种类、数量和胜利后的对白。用「分支架构图」检查路线，并为章节挑选适用的场景类型。剧本 JSON 可在工坊导入和导出，战役进度则从游戏里的「存档」面板管理。

「剧本背景与知识库」适合写时代、阵营、地理和人物资料。可以指定某条资料在到达特定章节或发现对应线索后开放。比如，把失踪者的最后行踪放在「搜到带印记的信」之后解锁。主持每轮检索当前剧本中有资格开放的资料。随机遭遇使用当前场景与剧本允许的敌人模板，适合把同一套规则用在不同题材里。

## 开发与规则来源

项目使用 Next.js App Router、React、TypeScript 和 Tailwind CSS。跑团与战斗规则位于 `lib/`，页面和服务接口位于 `app/`，界面组件位于 `components/`。

```bash
npm test
npm run typecheck
npm run lint
```

如需以生产模式运行，先停止开发服务，再构建并启动：

```bash
npm run build
npm run start -- -p 8080
```
